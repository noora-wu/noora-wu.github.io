CSSE7023：在 Java 里学面向对象

如果说 CSSE7030 用 Python 带我入了门，这门课则换成了 Java，把面向对象放到了正中间。

一门以面向对象为主线的课

CSSE7023 的先修课是 CSSE7030。主要教授的是 Java 的文件读写和图形界面（GUI）上。 类与对象、封装、继承、接口，这几块面向对象的基石，是这门课绕不开的内容。

和 Python 相比，Java 更「较真」：类型要写明，类和接口之间的关系要先想清楚， 很多问题在程序跑起来之前，就会被编译器拦下来。

作业与考试

Assignment 1 是把一款 1971 年的老游戏搬进 Java： Mike Mayfield 用 BASIC 写的文字版 Star Trek（STTR1）。原版是给电传打字机跑的过程式程序， 作业要求按照 Javadoc 规格，用面向对象的方式把它的核心重新写出来—— 8×8 个象限组成的银河、跃迁、能量、克林贡战舰——听起来像科幻，写起来是一整套封装、模块化与继承的练习。
