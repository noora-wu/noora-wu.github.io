一门把设计和代码拧在一起的课

DECO7140 Introduction to Web Design，主讲是 Dr Peter Worthy。 听说他的课向来作业特别多、特别麻烦——上完之后我想说：传言属实，但收获也属实。

课程把几条线拧在一起：UX 概念与 UI 设计模式，HTML / CSS / JavaScript 前端开发， 以及通过 API 串接数据。Studio 是实操的核心，每周把 Lecture 里的概念立刻落到手上。 评估大致包括多次线上主题探讨、两份报告，以及一个贯穿后半学期的个人网站项目。

对转行来读 IT 的我来说，这门课的位置很关键：一边补前端手感，一边建立「先想清楚用户，再动手写页面」的习惯。 后面的课、自己的作品集，都会反复用到这里打下的底座。

我的作品：Shanghai Cultural Heritage

期末项目老师给了几个主题方向，让我们选自己真正想做的内容。 我想借这个机会弘扬一下文化，于是选了上海——面向 Connect Communities Initiative（CCI）的叙事， 让不同背景的人走进这座城市的历史、节庆、社区与日常味道。

用 HTML / CSS / JavaScript 搭起来，并处理了轮播、筛选、地图、表单提交等交互。 开发时我刻意把无障碍放进默认清单里，以及尽量清晰的信息层级。

回过头看，我觉得这门课最重要的，是教会了我如何从零搭建一个完整网站： 结构怎么拆、样式怎么管、交互怎么接、无障碍怎么默认写进清单。它不只是交作业的文件， 而是我第一次完整走完：研究 → 提案 → 设计系统 → 前端实现 → 无障碍自查。

我带走了什么

说到底，DECO7140 最重要的收获是：我学会了从零搭建一个完整网站。 结构怎么拆、样式怎么管、交互怎么接。 作业确实又多又烦。但烦过之后留下的，是一套能继续用的手艺，和一个我愿意长期站在那边的立场： 网页可以漂亮，但首先，它应该进得去。
